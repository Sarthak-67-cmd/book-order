# 📚 Book Sticker Order

A simple website for ordering custom book stickers.

Students can enter their details, describe the sticker they want, choose the quantity, and select a payment method.

---

## 🌐 Website

**Live Website:**

https://sarthak-67-cmd.github.io/book-order/

---

## ✨ Features

- 🏷️ Custom sticker descriptions
- 👤 Student name
- 🎓 Class selection
- 🔤 Section selection
- 📱 WhatsApp phone number
- 📧 Optional email
- 🔢 Sticker quantity
- 💳 UPI payment option
- 💵 Cash payment option
- 📷 UPI QR code
- 📝 Additional order notes
- 📱 Mobile-friendly design

---

## 🛒 How to Place an Order

1. Open the website.
2. Click **Order Now**.
3. Describe the sticker you want.
4. Enter your student details.
5. Select the quantity.
6. Choose **UPI** or **Cash**.
7. If using UPI, scan the QR code and complete the payment.
8. Submit the order.

---

## 💳 Payment

Two payment methods are available.

### 📱 UPI

Scan the UPI QR code displayed on the order page and complete the payment.

### 💵 Cash

Choose the cash option if you want to pay when collecting your stickers.

> **Note:** The UPI QR code provides the payment destination, but the website does not automatically verify whether a payment was completed.
